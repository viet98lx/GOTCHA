# Human Presence Detection Using Active Acoustic Sensing
Description
We developed a prototype smart speaker system capable of detecting human presence in an enclosed space using active acoustic sensing. The system emits short chirp signals and records the reflected sound using an onboard microphone array. By analyzing the differences in echo patterns between scenarios with and without a person present, we can effectively infer human presence.

Our approach leverages the subtle variations in the acoustic response of the environment—caused by the human body altering the sound propagation path. We applied signal processing techniques and trained a lightweight machine learning model (Autoencoder Network) to distinguish between occupied and unoccupied conditions based on the time-frequency features of the recorded signals.

This project demonstrates a low-cost, privacy-preserving alternative to traditional vision-based sensing methods for smart home applications.
